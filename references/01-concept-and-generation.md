# 01. 设定图对齐与双路线生模指南

本阶段核心原则：**根据模型复杂度精准选路**，从源头杜绝烂拓扑、头身割裂与重复返工。

---

## 1. 路线决策：复杂模型 vs 简单模型

收到需求后，先做一次明确路由判断并在 `avatar-checklist.json` 中记录 `modeling_route`：

| 模型类型 | 典型例子 | 推荐路线 | 原因 |
| --- | --- | --- | --- |
| **复杂模型** | 二次元/写实完整人物、多层服饰、复杂发型、生物/兽耳精细角色 | **Tripo / Meshy**（网页或本地手动导出 GLB/FBX，再导入 Blender） | AI 生成有机体轮廓与基础贴图效率远高于手搓 |
| **简单模型** | Q 版简模、几何/硬表面道具、浮空机器人、胸针/发卡/光环/手持武器、基础短裙/披风 | **Blender 直接建模**（优先通过 Blender MCP 脚本化建模） | 布线绝对干净、零非流形、UV 天然规整、无需清理 AI 噪点 |

---

## 2. 复杂模型路线（Tripo / Meshy）

### 2.1 设定图准备（决定 70% 成败）
在喂给 Tripo 或 Meshy 之前，必须先核对参考图是否达标：
- **标准 T-Pose（或轻微 A-Pose）**：双臂自然伸平、双腿略微分开（防大腿内侧粘连）、五指张开清晰可见（防手指粘连成肉块）。
- **多视图对齐**：若同时提供正面与背面（或侧面）参考图，必须保证**同一角色、同一姿态、头顶与脚底基线及臂展像素级对齐**；若背视图质量不可靠或姿态不一致，宁可只用高质量单正面图，不要强行混入矛盾多视图。
- **去遮挡**：尽量避免长发完全盖住肩颈、披风完全盖住手臂、手持道具挡住躯干（道具应走简单模型路线单独在 Blender 建模，再由 MA 挂载）。

### 2.2 生成与导入铁律
1. **整体一次生成**：**禁止**把头和身体分开生成再拼接（颈部接缝、头身比例、肤色与光照烘焙几乎不可能无缝对齐）。
2. **禁止盲目抽卡**：每次只针对明确的问题（如手指粘连、裙摆塌陷）调整参考图后再生成，拿到 GLB/FBX 后立即进入 Blender 做灰模检验。
3. **保留只读原件**：将用户从 Tripo / Meshy 网页或客户端导出的 `.glb` / `.fbx` 放进 `raw/` 目录设为只读，导入 Blender 后立刻另存为 `01_raw_import.blend`。

## 3. 简单模型路线（Blender MCP 直接建模）

当判定为简单模型或独立配件时，直接通过 **Blender MCP** 用脚本化方式建模：
- **尺度与朝向一次到位**：
  - 单位为米（`1 Blender Unit = 1 Meter`）。
  - 角色/道具正面统一朝向 **`-Y`**，顶部朝向 **`+Z`**，脚底或锚点位于世界原点 `(0, 0, 0)`。
- **面向动画的布线纪律**：
  - 哪怕面数不限，关节弯曲处（肘、膝、腰、裙摆折叠处）必须使用**规整四边面循环边（Quad Edge Loops）**，至少保留 3 条关节环线以防弯曲塌陷。
  - 优先使用 `Subdivision Surface` / `Bevel` / `Solidify` 等非破坏性修改器调节质感，最终导出前再按需应用。
- **UV 与材质分槽同步规划**：
  - 建模时同步做好基础 `Smart UV Project` 或手动接缝展 UV，并按部位合理划分材质槽（例如 `Mat_Skin`、`Mat_Hair`、`Mat_Outfit`、`Mat_Metal`）。

## 4. 阶段 1 验收门禁（Gate 1）

通过 `scripts/blender_vrc_audit.py` + **最多 1 张 3 视图拼图（门禁 V1）** 确认以下指标：
- [ ] 头身比例符合设定图，无明显歪斜或肢体畸形。
- [ ] 双手五指可区分（无严重连成一片无法切开的肉块）。
- [ ] 关键独立件（头发、裙子、主要饰品）具备可拆分条件；如果头发和衣服严重糊死在脸/身体上无法拆件，**立刻在阶段 1 退回改图重生成**，绝不硬着头皮往下做。
- [ ] 已另存为 `01_raw_import.blend`，原始文件未被覆盖。
