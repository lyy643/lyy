# 02. 质量优先拆件、修模与分组件重贴图指南

本阶段核心原则：**以视觉质量与造型还原度为最高优先级，PC 主线不做破坏细节的暴力减面**；聚焦于“拆得干净、修掉坏几何、贴图高精、眼睛有神”。

---

## 1. 质量优先的拓扑与清理策略

与传统“为了塞进 70k 面疯狂 Decimate”不同，本 Skill 对 PC 主线采用**质量优先清理策略**：

1. **禁止盲目塌陷**：不要对整个角色无脑挂 `Decimate` 把五官、发丝、衣褶削成糊状。
2. **必须清理的“真垃圾”几何**（通过 Blender MCP 脚本 + `blender_vrc_audit.py` 自动定位）：
   - 重复顶点（`Merge by Distance`，极小阈值如 `0.0001m` 防止粘连眼睑/嘴唇）。
   - 翻转法线（`Recalculate Outside`，防止 Unity 里背面剔除变透明破洞）。
   - 零面积面、游离顶点/游离边、非流形破洞（重点修补面部、手部、接缝处）。
   - AI 生成模型内部残留的废碎块/内腔噪点。
3. **CATS 与 Mesh 工具的正确用法**（彻底不用 `mmd_tools`）：
   - 可使用 CATS 插件（社区兼容版）或标准 Blender Mesh 工具辅助做网格分离（By Loose Parts / By Material）、重命名整理、清除无效空组。
   - **警告**：不要直接点 CATS 的一键 `Fix Model` 把已经精细调好的骨骼、材质或高质量拓扑粗暴合烂——一切清理步骤应拆分为可回退的原子操作并另存版本。

---

## 2. 标准拆件清单（为后续绑骨、表情、MA 换装铺路）

在进入贴图与绑骨前，将模型合理拆分并规范命名（建议前缀统一，绝不用乱码或日文 MMD 命名）：

| 组件 | 拆分与修补要点 |
| --- | --- |
| `Body`（素体/面部） | 保留脸部与脖颈完整连续；若做服装开关（Toggle），被衣服遮挡处可保留或用透明遮罩（Mask）防穿模 |
| `Eyes` / `Face_Details` | 眼球、瞳孔高光、睫毛、眉毛建议分离或独立材质槽，方便眼追与精细着色 |
| `Mouth_Interior` | **必须检查口腔内部**：AI 生成模型默认闭嘴且没有口腔！要做张嘴/说话 Visemes，必须在嘴唇内侧挖出/补建口腔腔体、上下齿与舌头 |
| `Hair_Main` & `Hair_Strands` | 区分贴头皮的基底发与需要飘动物理的呆毛/马尾/鬓角发束；发根要有厚度和自然过渡 |
| `Outfit_*`（外衣/裙子/鞋袜） | 准备做 MA 换装或 PhysBone 物理的部件（如外套、裙摆）必须独立成 Mesh 或清晰独立分组 |
| `Accessory_*`（耳/尾/饰品） | 尾巴、兽耳、发饰独立拆件，确保根部穿插自然、无悬浮空隙 |

## 3. 分组件重贴图策略（按部位选最优法）

AI 原生生成的贴图常存在**背面模糊、光照死烘焙（衣服/脸上带黑影）、边缘渗色、眼睛糊掉**的问题，按组件分别处理：

1. **大面积服装与复杂花纹**：
   - 可通过 Tripo 重贴图或外部高精贴图回写 UV，或使用 Blender **多视角投影烘焙（Projection Painting / Baking）** 清理背面模糊。
   - **去烘焙阴影**：如果原生贴图把强烈高光/死黑阴影直接画死在 Albedo 上，必须在 Blender 贴图绘制或图像处理中拉平光影（交给 Unity 的 lilToon / Poiyomi 实时算阴影）。
2. **皮肤与手部**：
   - 保持柔和干净的肤色渐变，清理关节与指缝处的 AI 脏噪点；确保脸部与脖颈、身体交界处色号完全一致，无明显色差断层。
3. **硬表面/金属/纯色边饰**：
   - 优先平涂干净色块 + 独立 MatCap / Metallic / Roughness 贴图（供 Unity 着色器实时出金属光泽），比 AI 糊涂的高光贴图清晰十倍。
4. **眼睛精细化（决定二次元角色灵魂）**：
   - 眼白（Sclera）保持干净微暖白，顶部可加极柔和的上眼睑阴影过渡；
   - 虹膜（Iris）高分辨率绘制，清晰区分瞳孔、渐变层与高光层；
   - 眼部反光高光建议做在独立图层或靠 lilToon 的 **MatCap / 高光贴图** 实现，避免眼珠转动时高光死僵。

---

## 4. 贴图与材质规范（面向 Unity）

- **纹理尺寸**：质量优先前提下，主身体/面部/服装可用 `2048×2048` 或 `4096×4096` PNG；无透明通道的贴图不要无故保留全白 Alpha 通道。
- **材质命名**：全部用英文可读命名（如 `M_Skin`, `M_Face`, `M_Eye`, `M_Hair`, `M_Dress`, `M_Metal`），严禁出现 `Material.001`~`Material.048` 这种未整理废槽。
- **UV 校验**：每块 Mesh 必须拥有至少 1 套有效且无严重重叠错乱的 UV Map（尤其面部、眼睛和带文字/花纹区域）。

---

## 5. 阶段 2 验收门禁（Gate 2）

1. 通过 Blender MCP 运行 `scripts/blender_vrc_audit.py`，确认：
   - `non_manifold_edges`（关键面部/手部）清零或已记录为刻意开口（如裙底/袖口边缘）；
   - 无缺失 UV 的 Mesh，无空材质槽；
   - 缩放已归一（`scale == (1, 1, 1)`），朝向面向 `-Y`。
2. 输出 **门禁 V2**（全身正/背拼图 + 面部/眼部特写），确认无贴图接缝污染、无死黑烘焙、眼睛清晰有神。
3. 另存为 `03_textured.blend`。
